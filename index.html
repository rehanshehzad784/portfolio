03 — Practice

How a release actually leaves my desk.

  1. 01

    Review, then a real phone

    Git and Bitbucket before the build. If it crashes, it crashes on a device in hand, not in a slide.

  2. 02

    One codebase, many banks

    Include shipped as BEMO and FMFI. Flavor is a release decision, not a copy of the project.

  3. 03

    Write now, sync later

    Hive, SQLite, and CouchDB Lite are already in production apps that keep working on a weak network.

  4. 04

    Go-live is a place

    Include went live on-site in Syria. The release was the room, the devices, and the bank, not a tag in git.
